# MegaCD-Snatcher-Kr — 비공식 한글화 정식버전 V1.0

메가 CD 미국판 *Snatcher*의 비공식 한국어 패치입니다. 게임 속 문구·선택문과 함께 **음성 진행을 따라가는 한국어 보이스 자막**을 제공합니다.

> **보이스 자막에는 이 배포판의 전용 Genesis Plus GX 코어가 반드시 필요합니다.** 일반 코어만으로는 한국어 음성 자막이 나오지 않습니다. **게임 패치와 플랫폼에 맞는 전용 코어를 함께 사용하세요.**

자막은 게임 화면·페이지 넘김과 별도로 음성을 따라가며, 화면 아래쪽에 **흰 글자·얇은 검은 테두리**로 표시됩니다. 텍스트와 무관한 큰 검은 자막 상자를 만드는 방식이 아닙니다. **V1.0은 전체 대사 문맥 검수와 최근 교정을 반영한 비공식 정식 배포판**입니다.

[**V1.0 다운로드**](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/releases/tag/v1.0) · [변경 내역](docs/RELEASE-v1.0.md) · [패처 사용법](#패처-사용법)

비공식·비상업적 팬 프로젝트로 Konami, Sega, Libretro와 제휴하지 않았습니다. 여기서 “정식버전”은 **이 팬 한글패치의 정식 릴리스**를 뜻하며, 원작사 공식 제품이라는 의미가 아닙니다. 원본/패치 완료 게임 이미지·BIOS·RetroArch APK는 배포하지 않습니다. 사용자 소유의 정확한 미국판 원본 BIN과 별도 BIOS가 필요합니다.

## V1.0 변경 사항

- **전체 대사 문맥 검수 완료:** 본문·선택문 **10,728항목**, PCM 음성 자막 **고유 1,119대사(1,130등록)**, 기존 추가 CD 자막 **430쪽**, 별도 오프닝·회상·헌사·면책·엔딩 문구를 원문과 앞뒤 문맥으로 대조했습니다.
- **말투와 문맥 정리:** 길리언→메탈기어는 반말, 메탈기어→길리언은 존댓말, 랜덤은 반말이라는 기준을 유지했습니다. ACT 3 초반 약점 추론, 랜덤의 마지막 칭찬, 메탈의 겸양 표현, 조사·오역·어색한 문장을 교정했습니다. 다른 상대에게 하는 적절한 존대까지 일괄 치환하지 않았습니다.
- **누락 보이스 자막 3쪽 추가:** CD19의 `Wait! Wait for me!` → **“잠깐만요! 저를 기다려 주세요!”**, `Take me with you, please!` → **“제발 저도 데려가 주세요!”**, CD21의 `My arm!` → **“내 팔!”**을 복원했습니다. 추가 CD 음성 자막은 **428→431쪽**입니다.
- v0.95 이후 누적 변경은 **본문 27항목·기존 PCM 음성 5대사·추가 CD 자막 3쪽**입니다. 마지막 전체 검수에서 반영한 본문 17곳·PCM 3곳·누락 1절에, 그 전에 끝낸 ACT 3·랜덤·문법·CD19 교정이 합쳐져 있습니다.
- **Windows·Android·Linux 전용 코어를 모두 r61로 갱신**했습니다. 기존 흰 글씨·검은 테두리·하단 고정 표시와 음성 중심 동기화 방식, 오프닝과 기존 자막 시간표는 유지합니다. RetroArch 본체나 APK는 수정하지 않습니다.
- 이전의 해리 장면 `길리언, 이분은 곧...`, `기억` 메뉴, `접수처`, `위로하기`, `에.. 에취!`, 표시 영문 대문자, `깁슨(GIBSON)`·`카트리나(KATRINA)`·`나폴레옹(NAPOLEON)` 및 `베릴륨(BE)`·질소·황·산소 퍼즐 힌트를 유지합니다.

## 패처 사용법

1. [V1.0 릴리스](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/releases/tag/v1.0)에서 **`SnatcherKRInstaller.exe`** 또는 **`MegaCD-Snatcher-Kr-v1.0-Windows-Patcher.zip`**을 받습니다. 패처는 **Windows 64비트용**입니다.
2. 본인이 보유한 미국판 원본 **`Snatcher (USA).bin`**을 준비합니다. **625,192,176바이트**, SHA-256 **`8d6f4dba8d9ce59991be9f65635047adc3b0f37ea2358f8c48b251883c9e55b6`**, CRC32 **`3faf807d`**만 입력으로 받습니다. 다른 덤프·리전·이미 패치된 BIN은 거부합니다.
3. 결과를 넣을 **존재하는 빈 폴더**와 약 **700MB 이상**의 여유 공간을 준비합니다. ZIP을 받았다면 압축을 푼 뒤 EXE를 실행합니다. 보안 경고가 뜨면 발행자와 아래 파일 해시를 확인하고 실행 여부를 판단하세요.
4. **원본 BIN 선택 → 결과 폴더 선택 → 게임 패치하고 코어 3종 내보내기**를 누릅니다. 패처가 원본 크기·SHA·CRC를 확인하고 BPS 적용 후 결과와 동봉 파일 해시를 검사합니다. 원본이나 기존 동명 파일을 덮어쓰지 않습니다.
5. 출력된 **`Snatcher-KR-v1.0.bin`과 `Snatcher-KR-v1.0.cue`를 함께 보관**합니다. RetroArch에서는 **BIN이 아니라 CUE**를 엽니다. CD 오디오 트랙 구성을 유지하기 위해서입니다.
6. 사용하는 플랫폼의 **V1.0 동봉 전용 코어(r61)**를 설치·선택한 뒤 CUE를 실행합니다. BIOS는 사용자가 별도로 준비하고 RetroArch의 안내에 따라 설정해야 합니다.

### 플랫폼별 전용 코어

| 플랫폼 | 파일 | 확인 범위 |
| --- | --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` | r61, DLL 로드·libretro API 1·최신 자막 내장 및 EXE 실적용 출력 해시 확인 |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` | r61, NDK r30 빌드·ELF64 AArch64·필수 함수 확인. 실제 Android 기기 로딩·게임 재생은 미검증 |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` | r61, Ubuntu 24.04 빌드·ELF·의존성·동적 로드/API 1 확인. 실제 게임 재생은 미검증 |

Windows에서는 DLL을 RetroArch에서 직접 불러오거나 사용자 코어 위치에 둡니다. Android에서는 ARM64 SO를 기기로 옮겨 해당 RetroArch의 외부 코어 설치/가져오기 기능을 사용합니다. Linux에서는 Linux SO와 같은 이름의 `.info`를 코어/코어 정보 위치에 두거나 해당 SO를 직접 불러옵니다. 설치된 RetroArch 버전·배포 방식에 따라 메뉴와 경로가 다를 수 있으므로 해당 환경의 안내를 따르세요. **Android용 SO와 Linux용 SO는 서로 바꿔 쓸 수 없습니다.**

패처는 게임 BIN/CUE, Windows DLL, Android ARM64 SO, Linux x86_64 SO, 코어 정보 `.info`, 코어·글꼴 라이선스, 완전한 개조 소스 ZIP 및 빌드 기록을 출력합니다. **APK를 생성하거나 RetroArch 본체를 수정하지 않습니다.**

### Windows 없이 수동 적용

릴리스에서 `Snatcher-KR-v1.0.bps`, `Snatcher-KR-v1.0.cue`와 해당 플랫폼 전용 코어를 따로 받습니다. BPS 지원 패처로 **위 해시의 원본 BIN → BPS → 새 결과 BIN** 순서로 적용하세요. 결과 이름을 `Snatcher-KR-v1.0.bin`으로 맞춰 CUE와 같은 폴더에 두고, 결과 해시가 아래와 일치하는지 확인합니다. 수동 적용도 **r61 전용 코어가 필수**입니다.

### 이전 버전에서 업데이트

**v0.95 이하 사용자는 미국판 원본에서 V1.0으로 다시 패치하고, 전용 코어도 함께 교체해야 합니다.** 이미 패치된 BIN에 덧씌우지 마세요. 구 코어를 재사용하면 수정 전 음성 자막이 나오며, CUE와 다른 이름의 BIN을 섞으면 게임이 열리지 않습니다.

저장 파일은 먼저 백업하세요. 예전 세이브스테이트에는 수정 전 데이터가 메모리에 남을 수 있으므로 게임을 완전히 다시 실행한 뒤 **게임 내 저장을 불러오고 해당 장소에 재진입**하는 편이 좋습니다. 게임 파일명 변경으로 저장이 보이지 않으면 기존 저장을 보존한 채 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

## 확인 범위와 알려진 제한

- 마지막 전체 대사 검수의 변경 범위·원문·페이지·시각·비트맵·기존 수정 보존 검사 **55/55** 통과. 이번 배포의 설치기/BPS/최종 교정/C 자막 선택기 표적 검사 **40/40** 통과입니다. 두 시험 묶음에는 겹치는 항목이 있어 합쳐서 고유 95개라고 부르지 않습니다.
- 변경 본문 17개를 실제 M68000 텍스트 리더로 46회 실행했고, 기능 키 43개와 기존 글꼴·음원·명령 데이터를 보존했습니다.
- BPS를 두 번 생성해 바이트 일치를 확인했고 전체 패치 동작·CRC·목표 바이트를 대조했습니다. **최종 배포 EXE에 원본을 실제 적용한 출력 11/11** 크기·SHA-256·CRC32 일치와 원본 불변을 확인했습니다.
- 실제 제품의 C 자막 선택기를 분리 실행해 추가 CDDA 13트랙·431쪽의 전체 해당 구간과 표시 조건, 흰 글자·검은 윤곽·비잉크 영역·게임 RAM 불변을 검사했습니다. 기존 430쪽에서 한 쪽을 추가하는 마지막 단계에서도 기존 문구·시각·그림을 보존했습니다.
- 같은 980개 소스로 만든 코어 3종에서 **전체 자막 비트맵 은행 33개**의 동일성을 확인했습니다. 자막 헤더 외 나머지 979개 소스는 이전 배포와 동일합니다. [Linux 빌드·동적 로드·API 1 기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/40024589478).
- 전체 **텍스트 문맥 대조 완료**와 전편의 모든 음성 재청취·게임 분기 재플레이는 다릅니다. 이번 배포를 위해 전편 재플레이, Android/Linux 실제 게임 재생, 실기 검증을 새로 수행하지는 않았습니다. 플랫폼별 미검증 사항은 아래 설명대로 유지합니다.

문제가 발생하면 플랫폼·코어 해시·게임 BIN SHA-256, 장면, 재현 순서와 화면을 함께 알려 주세요. 게임/BIOS 파일은 첨부하지 마세요. NDS 포팅은 별도 프로젝트이며 이 메가 CD 배포에는 NDS 실행파일이 없습니다.
