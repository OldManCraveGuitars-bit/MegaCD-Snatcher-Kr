# MegaCD-Snatcher-Kr — v0.95 시험판

메가 CD 미국판 *Snatcher*의 한국어 패치입니다. 게임 속 문구·선택문뿐 아니라 **음성에 맞춰 표시되는 한국어 자막**을 중점적으로 다룹니다. 자막은 게임의 페이지 넘김과 별도로 음성 진행을 따르도록 만든 **전용 Genesis Plus GX 코어**에서 그립니다. 화면 아래쪽의 흰 글자·검은 테두리 방식이며, 별도의 큰 검은 자막 상자를 만드는 방식이 아닙니다.

> **중요: 일반 Genesis Plus GX 코어만으로는 보이스 자막이 나오지 않습니다.** 이 배포판과 짝을 이루는 개조 코어를 반드시 사용하세요. 게임 BIN만 패치한 뒤 기본 코어에서 실행하는 것은 지원하는 완성 구성으로 간주하지 않습니다.

이 저장소와 배포 파일에는 원본 게임 이미지, 패치 완료된 전체 게임 이미지, BIOS, RetroArch APK가 없습니다. 본인이 보유한 정확한 미국판 BIN과 별도 BIOS가 필요합니다. 비공식·비상업적 팬 프로젝트이며 Konami, Sega, Libretro와 제휴하지 않았습니다. **v0.95는 시험판**입니다. 최근 제보된 말투·메뉴·영문 힌트 표기를 고치고, 해리 장면에서 빠진 메탈기어 보이스 자막을 복원했습니다. 전체 등장인물의 문맥 재검수 완료나 전편 모든 분기 플레이·모든 기기의 동작 보증을 뜻하지 않습니다.

## v0.95 변경 사항

- **해리 장면의 메탈기어 자막 한 문장 복원:** 원음 `Gillian, he's about...`에 맞춰 **`길리언, 이분은 곧...`**을 추가했습니다. CD12의 185.86–187.80초이며, 말을 흐리는 원문을 완성 문장으로 바꾸지 않았습니다. 추가 CD 음성 자막은 427→428쪽이고 기존 427쪽의 시간표는 유지했습니다.
- **길리언→메탈기어는 반말, 메탈기어→길리언은 존댓말**로 혼용 사례를 교정했습니다. ACT 2 아파트, 제이미 통화 중 메탈의 설명, 터보사이클 탈출, 후반 대화 등을 포함합니다. 다른 사람에게 말하는 적절한 존댓말까지 일괄 치환하지 않았습니다.
- **랜덤의 존댓말 잔여를 반말로 교정**했습니다. 병원 버튼 장치 설명의 `행동할 위험을 막는 장치입니다`는 `행동할 위험을 막는 장치야`로 바꿨습니다.
- 기억에 관한 질문 메뉴는 **`메모리`→`기억`**으로 바꿨습니다. 번역 문구·자막 속 영문은 **대문자**로 통일했습니다. 예: `OLEEN`, `OLEENS`, `OLEENA`, `QUEEN`, `QUEENS`. 원본 그래픽·프로그램 코드·정답 입력 판정키를 대문자로 덮어쓴 것은 아닙니다.
- 원소 퍼즐의 본문과 보이스에 **`베릴륨(BE)`, `질소(N)`, `황(S)`, `산소(O)`**를 표기했습니다. 반복 질문과 원소 배열 순서, `BENSON` 해독은 보존했습니다. `BE`는 이 게임의 대문자 표시 규칙입니다.
- **Windows·Android·Linux 전용 코어를 모두 r57로 갱신**했습니다. **v0.9 이하 사용자는 미국판 원본에서 게임을 다시 패치하고, 전용 코어도 함께 교체하세요.** RetroArch 본체/APK는 수정하지 않습니다.
- 기존 국장 회상 말투, 나폴레옹·깁슨·카트리나 영문 힌트, `위로하기`, 재채기 `에.. 에취!`, 미카 존댓말, `접수처` 교정을 유지합니다. 오프닝·원음·기존 자막 시간표와 **하단 흰 글씨·검은 테두리** 렌더러는 그대로입니다. 새 시간 구간은 위 누락 문장 한 곳뿐입니다.

## 받기 전에 확인할 것

1. [v0.95 릴리스](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/releases/tag/v0.95)에서 `SnatcherKRInstaller.exe` 또는 같은 EXE가 든 ZIP을 받습니다. **Windows 64비트용 패처**이며 APK 생성기나 RetroArch 수정 도구가 아닙니다.
2. 본인이 보유한 미국판 원본 `Snatcher (USA).bin`을 준비합니다. 파일 크기 **625,192,176바이트**, SHA-256 **`8d6f4dba8d9ce59991be9f65635047adc3b0f37ea2358f8c48b251883c9e55b6`**, CRC32 **`3faf807d`**만 입력으로 받습니다. 다른 덤프·다른 리전·이미 수정된 BIN은 거부합니다.
3. 결과를 넣을 **이미 존재하는 빈 폴더**를 준비합니다. 약 **700MB 이상**의 여유 공간이 필요합니다. 패처는 동명 파일을 덮어쓰지 않습니다.

## 패처 사용법

1. ZIP으로 받았다면 압축을 풀고 `SnatcherKRInstaller.exe`를 실행합니다. Windows 보안 경고가 뜨면 발행자와 [아래 SHA-256](#sha-256-검증)을 확인한 뒤 본인이 실행 여부를 판단하세요.
2. **원본 BIN 선택**에서 위의 `Snatcher (USA).bin`을 지정합니다. 패처가 크기·SHA-256·CRC32를 확인합니다.
3. **결과 폴더 선택**에서 빈 폴더를 지정하고 설치를 누릅니다. 패처가 BPS를 적용한 뒤 출력 BIN과 동봉 파일의 해시를 확인합니다. 실패하면 원본 BIN은 바뀌지 않습니다.
4. 결과 폴더에서 `Snatcher-KR-v0.95.bin`과 `Snatcher-KR-v0.95.cue`를 **함께 보관**합니다. RetroArch에서 게임을 열 때는 **`.bin`이 아니라 `.cue`**를 선택하세요. 이렇게 해야 CD 오디오 트랙 참조를 유지할 수 있습니다.
5. 사용하는 플랫폼에 맞는 **전용 코어**를 설치·선택하고 게임 `.cue`를 엽니다. 일반 코어로 열면 한국어 보이스 자막 기능이 빠집니다. BIOS는 RetroArch 안내에 따라 사용자가 별도로 설정해야 합니다.

### 플랫폼별 코어

| 플랫폼 | 전용 코어 파일 | 상태 |
| --- | --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` | r57. DLL 로드와 수정 자막 포함, 패처 실제 적용 후 출력 해시를 확인했습니다. 이번 교정판의 새 전편 플레이 검증은 아닙니다. |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` | 패처가 함께 출력합니다. APK는 수정하지 않습니다. 실제 Android 기기의 코어 로딩·게임 재생은 아직 미검증입니다. |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` | 패처가 함께 출력하고, 릴리스에서 단독으로도 받을 수 있습니다. Ubuntu 24.04 x86_64에서 빌드·ELF/의존성·동적 로드/libretro API 검사를 통과했습니다. 게임 재생은 미검증입니다. |

Windows에서는 출력된 DLL을 RetroArch의 사용자 코어 위치에 복사하거나 코어 파일을 직접 불러옵니다. Android에서는 출력된 ARM64 SO를 기기로 옮긴 뒤 기기 RetroArch에서 외부 코어 설치/가져오기 기능을 사용합니다. Linux에서는 Linux x86_64 SO와 같은 이름의 `.info`를 코어 및 코어 정보 위치에 두거나 해당 SO를 직접 불러옵니다. 버전·배포 방식에 따라 메뉴 이름과 코어 경로가 다를 수 있으므로 설치된 RetroArch의 안내를 확인하세요. Android용 SO를 Linux용으로, Linux용 SO를 Android용으로 바꿔 쓸 수는 없습니다.

패처는 게임 BIN/CUE, Windows DLL, Android ARM64 SO, Linux x86_64 SO, 코어 정보 `.info`, 코어·폰트 라이선스, 개조 코어의 전체 소스 ZIP과 빌드 기록을 한 폴더에 출력합니다. 원본 BIN, 기존 파일, RetroArch 설치본은 덮어쓰지 않습니다.

### Windows 없이 수동 적용하기

Linux/Android만 사용하는 사람을 위해 릴리스에 `Snatcher-KR-v0.95.bps`, 결과용 `Snatcher-KR-v0.95.cue`, 플랫폼별 전용 코어도 개별 자산으로 제공합니다. BPS 지원 패처에서 **위 해시의 원본 BIN → BPS → 새 결과 BIN** 순서로 적용하세요. 결과 BIN 이름을 `Snatcher-KR-v0.95.bin`으로 맞추고, 릴리스의 `Snatcher-KR-v0.95.cue`와 같은 폴더에 두세요. CUE 안의 `FILE` 지시문이 이 BIN을 가리킵니다. 결과 SHA-256이 아래 값과 일치해야 합니다. 이 경로에서는 v0.95의 r57 전용 코어도 별도로 받아야 하며, 원본·결과 게임 자체는 릴리스에 없습니다.

**v0.9 이하 사용자는 미국판 원본에서 v0.95로 다시 패치하고 전용 코어도 함께 교체하세요.** 이미 패치한 BIN에는 덧씌우지 않습니다. 구 코어를 재사용하면 수정 전 보이스 자막이 나옵니다. 새 CUE만 이전 이름의 BIN 옆에 섞으면 열리지 않습니다. 저장 파일은 먼저 백업하세요. 예전 세이브스테이트에는 수정 전 대사 데이터가 메모리에 남아 있을 수 있으므로, 게임을 완전히 다시 실행한 뒤 **게임 내 저장을 불러오고 해당 장소에 재진입**하는 방식을 권장합니다. 게임 파일명이 바뀌어 저장이 보이지 않으면 원래 저장 파일을 보존한 채 사용 중인 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

Windows PowerShell에서 수동 확인: `Get-FileHash -Algorithm SHA256 -LiteralPath '파일경로'`. Linux에서는 `sha256sum '파일경로'`를 사용할 수 있습니다. 파일명보다 **해시**를 우선하여 판별하세요. ZIP을 포함한 모든 배포 파일은 [SHA256SUMS-v0.95.txt](SHA256SUMS-v0.95.txt)에 기록합니다.

## 확인 범위와 알려진 제한

- 이번 배포 표적 **자동시험51/51** 통과. 설치기·원소 힌트·길리언/메탈/랜덤 교정·해리 누락 및 실제 C 자막 선택기 검사를 포함합니다. 이미 끝낸 전편/3인 초상화 재생을 반복한 것이 아닙니다.
- 원소 본문6항목의 M68000 읽기22구간, 영문 대문자 본문33항목의 읽기110구간과 입력 판정키184개 보존은 해당 로컬 수정 때 확인했습니다. 표기 변경과 프로그램/정답 키 변경을 구분했습니다.
- BPS 2회 생성 일치와 전체 적용 동작·CRC·목표 바이트 대조를 확인했습니다. **최종 배포 EXE의 원본 실적용 출력11/11** 해시·크기·CRC 일치, 원본 불변을 확인했습니다. GUI 관찰이나 전체 게임 플레이 시험과는 구분합니다.
- 실제 제품의 C 자막 소비·합성 코드를 분리 실행해 추가 CDDA 13트랙·428쪽의 시각 선택과 흰 글씨·검정 윤곽·비잉크 영역·게임RAM 불변을 검사했습니다. 말투 교정을 먼저 반영한 뒤, 누락 복원 단계에서는 기존427쪽 내용/시각/그림을 그대로 두고 메탈의 미완성 문장 한 쪽만 추가했습니다. 새 원음 재분석은 기계 전사이며 사람 청취 승인과 다릅니다.
- 같은980소스에서 Windows·Android·Linux r57 코어를 준비하고 **33개 전체 자막 비트맵 은행**이 3종 모두 동일하게 들어 있는지 확인했습니다. v0.9 소스와의 차이는 자막 헤더1파일이며 나머지979파일은 같습니다. [이번 Linux 빌드·ELF·동적로드/API1 기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/39833394506), 전체 소스·라이선스·빌드 기록을 제공합니다.
- **전체 등장인물의 전 대사 재검수 완료는 아닙니다.** 새 전편 청취·플레이·Android/Linux 실제 게임·실기 검증은 수행하지 않았습니다. 이미 해결한3인 초상화 반복 재생은 생략하고 기존 실제 화면을 촬영 버전과 함께 보존했습니다.
