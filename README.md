# MegaCD-Snatcher-Kr — v0.8 시험판

메가 CD 미국판 *Snatcher*의 한국어 패치입니다. 게임 속 문구·선택문뿐 아니라 **음성에 맞춰 표시되는 한국어 자막**을 중점적으로 다룹니다. 자막은 게임의 페이지 넘김과 별도로 음성 진행을 따르도록 만든 **전용 Genesis Plus GX 코어**에서 그립니다. 화면 아래쪽의 흰 글자·검은 테두리 방식이며, 별도의 큰 검은 자막 상자를 만드는 방식이 아닙니다.

> **중요: 일반 Genesis Plus GX 코어만으로는 보이스 자막이 나오지 않습니다.** 이 배포판과 짝을 이루는 개조 코어를 반드시 사용하세요. 게임 BIN만 패치한 뒤 기본 코어에서 실행하는 것은 지원하는 완성 구성으로 간주하지 않습니다.

이 저장소와 배포 파일에는 원본 게임 이미지, 패치 완료된 전체 게임 이미지, BIOS, RetroArch APK가 없습니다. 본인이 보유한 정확한 미국판 BIN과 별도 BIOS가 필요합니다. 비공식·비상업적 팬 프로젝트이며 Konami, Sega, Libretro와 제휴하지 않았습니다. **v0.8은 시험판**입니다. 이번에는 확인된 소개·퍼즐 힌트·행동 메뉴를 교정했습니다. 전체 문맥 재검수는 아직 완료되지 않았으며, 전편 모든 분기 플레이나 모든 기기의 동작 보증을 뜻하지 않습니다.

## v0.8 변경 사항

- 초반 본부에서 깁슨·카트리나를 반복해서 물을 때 나오는 **소개 답변9개 모두에 `깁슨(GIBSON)`·`카트리나(KATRINA)`를 병기**했습니다. 관련 소개7개와 조던 프로필2개도 함께 보완했습니다.
- 조던의 카트리나 정보에 **`허벅지(THIGH)`**, **`하트(HEART) 모양 반점(BIRTHMARK)`**을 표시합니다. 영문을 직접 입력해야 하는 퍼즐의 힌트를 한국어만 보고 놓치지 않도록 했으며, 정답 입력 키 자체는 바꾸지 않았습니다.
- 미카·카트리나 대화의 행동 메뉴 **`콘솔`을 `위로하기`로 수정**했습니다. 이 문맥의 CONSOLE은 장치가 아니라 위로한다는 동사입니다.
- v0.778 대비 본문 **20항목**이 바뀝니다. 보이스 자막·시간표·오프닝·전용 코어3종은 **v0.778 r50과 바이트 동일**합니다. 기존 재채기 “에.. 에취!”, 미카 존댓말, “접수처” 수정도 유지합니다.
- **이번에는 게임을 원본에서 다시 패치해야 합니다.** 코어만 교체하면 새 본문 수정이 적용되지 않습니다. 이미 v0.778 r50 코어를 사용 중이라면 그대로 사용해도 됩니다. RetroArch 본체/APK는 수정하지 않습니다.

## 받기 전에 확인할 것

1. [v0.8 릴리스](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/releases/tag/v0.8)에서 `SnatcherKRInstaller.exe` 또는 같은 EXE가 든 ZIP을 받습니다. **Windows 64비트용 패처**이며 APK 생성기나 RetroArch 수정 도구가 아닙니다.
2. 본인이 보유한 미국판 원본 `Snatcher (USA).bin`을 준비합니다. 파일 크기 **625,192,176바이트**, SHA-256 **`8d6f4dba8d9ce59991be9f65635047adc3b0f37ea2358f8c48b251883c9e55b6`**, CRC32 **`3faf807d`**만 입력으로 받습니다. 다른 덤프·다른 리전·이미 수정된 BIN은 거부합니다.
3. 결과를 넣을 **이미 존재하는 빈 폴더**를 준비합니다. 약 **700MB 이상**의 여유 공간이 필요합니다. 패처는 동명 파일을 덮어쓰지 않습니다.

## 패처 사용법

1. ZIP으로 받았다면 압축을 풀고 `SnatcherKRInstaller.exe`를 실행합니다. Windows 보안 경고가 뜨면 발행자와 [아래 SHA-256](#sha-256-검증)을 확인한 뒤 본인이 실행 여부를 판단하세요.
2. **원본 BIN 선택**에서 위의 `Snatcher (USA).bin`을 지정합니다. 패처가 크기·SHA-256·CRC32를 확인합니다.
3. **결과 폴더 선택**에서 빈 폴더를 지정하고 설치를 누릅니다. 패처가 BPS를 적용한 뒤 출력 BIN과 동봉 파일의 해시를 확인합니다. 실패하면 원본 BIN은 바뀌지 않습니다.
4. 결과 폴더에서 `Snatcher-KR-v0.8.bin`과 `Snatcher-KR-v0.8.cue`를 **함께 보관**합니다. RetroArch에서 게임을 열 때는 **`.bin`이 아니라 `.cue`**를 선택하세요. 이렇게 해야 CD 오디오 트랙 참조를 유지할 수 있습니다.
5. 사용하는 플랫폼에 맞는 **전용 코어**를 설치·선택하고 게임 `.cue`를 엽니다. 일반 코어로 열면 한국어 보이스 자막 기능이 빠집니다. BIOS는 RetroArch 안내에 따라 사용자가 별도로 설정해야 합니다.

### 플랫폼별 코어

| 플랫폼 | 전용 코어 파일 | 상태 |
| --- | --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` | 패처가 함께 출력합니다. Windows 실행·출력 해시 검증을 수행했습니다. |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` | 패처가 함께 출력합니다. APK는 수정하지 않습니다. 실제 Android 기기의 코어 로딩·게임 재생은 아직 미검증입니다. |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` | 패처가 함께 출력하고, 릴리스에서 단독으로도 받을 수 있습니다. Ubuntu 24.04 x86_64에서 빌드·ELF/의존성·동적 로드/libretro API 검사를 통과했습니다. 게임 재생은 미검증입니다. |

Windows에서는 출력된 DLL을 RetroArch의 사용자 코어 위치에 복사하거나 코어 파일을 직접 불러옵니다. Android에서는 출력된 ARM64 SO를 기기로 옮긴 뒤 기기 RetroArch에서 외부 코어 설치/가져오기 기능을 사용합니다. Linux에서는 Linux x86_64 SO와 같은 이름의 `.info`를 코어 및 코어 정보 위치에 두거나 해당 SO를 직접 불러옵니다. 버전·배포 방식에 따라 메뉴 이름과 코어 경로가 다를 수 있으므로 설치된 RetroArch의 안내를 확인하세요. Android용 SO를 Linux용으로, Linux용 SO를 Android용으로 바꿔 쓸 수는 없습니다.

패처는 게임 BIN/CUE, Windows DLL, Android ARM64 SO, Linux x86_64 SO, 코어 정보 `.info`, 코어·폰트 라이선스, 개조 코어의 전체 소스 ZIP과 빌드 기록을 한 폴더에 출력합니다. 원본 BIN, 기존 파일, RetroArch 설치본은 덮어쓰지 않습니다.

### Windows 없이 수동 적용하기

Linux/Android만 사용하는 사람을 위해 릴리스에 `Snatcher-KR-v0.8.bps`, 결과용 `Snatcher-KR-v0.8.cue`, 플랫폼별 전용 코어도 개별 자산으로 제공합니다. BPS 지원 패처에서 **위 해시의 원본 BIN → BPS → 새 결과 BIN** 순서로 적용하세요. 결과 BIN 이름을 `Snatcher-KR-v0.8.bin`으로 맞추고, 릴리스의 `Snatcher-KR-v0.8.cue`와 같은 폴더에 두세요. CUE 안의 `FILE` 지시문이 이 BIN을 가리킵니다. 결과 SHA-256이 아래 값과 일치해야 합니다. 이 경로에서는 전용 코어도 별도로 받아야 하며, 원본·결과 게임 자체는 릴리스에 없습니다.

**v0.778 이하 게임 및 로컬 힌트 r1/r2/r3 사용자는 미국판 원본에서 v0.8로 다시 패치하세요.** 이미 패치한 BIN에는 덧씌우지 않습니다. 기존 v0.778 r50 코어는 그대로 쓸 수 있고, 이전 코어 사용자는 동봉 코어로 교체하세요. 새 CUE만 이전 이름의 BIN 옆에 섞으면 열리지 않습니다. 저장 파일은 먼저 백업하세요. 예전 세이브스테이트에는 수정 전 대사 데이터가 메모리에 남아 있을 수 있으므로, 게임을 완전히 다시 실행한 뒤 **게임 내 저장을 불러오고 해당 장소에 재진입**하는 방식을 권장합니다. 게임 파일명이 바뀌어 저장이 보이지 않으면 원래 저장 파일을 보존한 채 사용 중인 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

## 확인 범위와 알려진 제한

- 원문 메뉴 분기에서 미카·카트리나를 위로하는 행동임을 확인했고, 초반 본부의 반복 소개 답변9개를 각각 대조했습니다. 다른 지역의 모든 수사·잡담을 소개로 간주해 이름을 일괄 추가한 것은 아닙니다.
- 변경 범위·입력 거부·설치·텍스트 편집기 관련 **자동시험102개 통과**. 실제 설치된 M68000 메뉴 루틴을 분리 실행하여 새 메뉴18경우와 기존 접수처30경우를 검사했습니다. 소개·힌트18항목의 대사 읽기88구간도 검사했습니다.
- 앞선 로컬 힌트r3에 마지막 메뉴 수정을 통합할 때 전체265,813섹터 중4섹터만 달라졌고, 나머지 섹터·ISO 구조·CUE 트랙 구조와 수정 섹터의 EDC/ECC를 확인했습니다. 기존 글꼴/본문/음성 주소 및 퍼즐 정답 키는 유지합니다.
- BPS를 두 번 생성해 동일함을 확인하고, 원본에서 목표 결과로 적용되는 모든 패치 동작과 CRC를 대조했습니다. 최종 EXE의 원본 실적용 결과는 [릴리스 기록](docs/RELEASE-v0.8.md)에 명시합니다.
- Windows/Android/Linux r50 코어와 전체 코어 소스·라이선스·빌드 기록을 v0.778과 동일하게 동봉합니다. 기존 Linux 빌드·ELF/의존성·동적로드/API1 [기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/39104147418)을 재사용하며, 이번에 다시 빌드했다는 뜻이 아닙니다.
- 기존 미카 존대·접수처·재채기·오프닝·추가 CD 자막은 유지합니다. 이미 해결한3인 초상화나 전편 플레이를 반복하지 않았습니다.
- **전체 문맥 재검수는 진행 중이며 v0.8에서 완료로 선언하지 않습니다.** 새 게임 장면 재플레이·새 스크린샷·전편 청취/번역 승인·Android/Linux 실제 게임·실기 검증도 수행하지 않았습니다. 기존 실제 화면은 촬영 버전과 함께 보존했습니다.
- 문제가 발생하면 화면, 플랫폼·코어 해시, 게임 BIN SHA-256, 장면과 재현 순서를 함께 알려 주세요. 게임/BIOS 파일은 첨부하지 마세요.
