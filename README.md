# MegaCD-Snatcher-Kr — v0.776 시험판

메가 CD 미국판 *Snatcher*의 한국어 패치입니다. 게임 속 문구·선택문뿐 아니라 **음성에 맞춰 표시되는 한국어 자막**을 중점적으로 다룹니다. 자막은 게임의 페이지 넘김과 별도로 음성 진행을 따르도록 만든 **전용 Genesis Plus GX 코어**에서 그립니다. 화면 아래쪽의 흰 글자·검은 테두리 방식이며, 별도의 큰 검은 자막 상자를 만드는 방식이 아닙니다.

> **중요: 일반 Genesis Plus GX 코어만으로는 보이스 자막이 나오지 않습니다.** 이 배포판과 짝을 이루는 개조 코어를 반드시 사용하세요. 게임 BIN만 패치한 뒤 기본 코어에서 실행하는 것은 지원하는 완성 구성으로 간주하지 않습니다.

이 저장소와 배포 파일에는 원본 게임 이미지, 패치 완료된 전체 게임 이미지, BIOS, RetroArch APK가 없습니다. 본인이 보유한 정확한 미국판 BIN과 별도 BIOS가 필요합니다. 비공식·비상업적 팬 프로젝트이며 Konami, Sega, Libretro와 제휴하지 않았습니다. **v0.776은 시험판**입니다. 번역 목록과 추가 음성을 대조했지만, 전편 모든 분기 플레이나 사람 번역가의 최종 승인, 모든 기기의 동작 보증을 뜻하지는 않습니다.

## v0.776 변경 사항

- 미카가 있는 정커 본부 접수처를 가리키는 **FRONT 메뉴를 “접수처”로 수정**했습니다. SP08·SP21의 “전면”과 후반 SP33의 “앞쪽”, 총3항목·7개 메뉴 연결에 반영했습니다.
- 원본 이동 메뉴와 주변 대사를 확인해 장소명만 수정했습니다. 폐허의 막힌 앞길(SP07), 터널 앞쪽(SP32)처럼 실제 방향을 뜻하는 FRONT는 바꾸지 않았습니다.
- 다른10,725항목, 음성·보이스 자막·오프닝 타이밍·폰트·그림·자막 렌더러는 그대로입니다. Windows·Android·Linux 전용 코어도 **v0.775 r48과 동일한 파일**입니다.
- **이번에는 게임 BIN/BPS가 바뀝니다.** v0.775 사용자도 원본 BIN에 v0.776 패처를 적용해 새 BIN/CUE로 실행해야 장소명이 바뀝니다. 코어만 교체해서는 적용되지 않습니다. 이미 v0.775 전용 코어를 쓰고 있다면 해당 코어는 계속 사용해도 됩니다.

## 받기 전에 확인할 것

1. [v0.776 릴리스](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/releases/tag/v0.776)에서 `SnatcherKRInstaller.exe` 또는 같은 EXE가 든 ZIP을 받습니다. **Windows 64비트용 패처**이며 APK 생성기나 RetroArch 수정 도구가 아닙니다.
2. 본인이 보유한 미국판 원본 `Snatcher (USA).bin`을 준비합니다. 파일 크기 **625,192,176바이트**, SHA-256 **`8d6f4dba8d9ce59991be9f65635047adc3b0f37ea2358f8c48b251883c9e55b6`**, CRC32 **`3faf807d`**만 입력으로 받습니다. 다른 덤프·다른 리전·이미 수정된 BIN은 거부합니다.
3. 결과를 넣을 **이미 존재하는 빈 폴더**를 준비합니다. 약 **700MB 이상**의 여유 공간이 필요합니다. 패처는 동명 파일을 덮어쓰지 않습니다.

## 패처 사용법

1. ZIP으로 받았다면 압축을 풀고 `SnatcherKRInstaller.exe`를 실행합니다. Windows 보안 경고가 뜨면 발행자와 [아래 SHA-256](#sha-256-검증)을 확인한 뒤 본인이 실행 여부를 판단하세요.
2. **원본 BIN 선택**에서 위의 `Snatcher (USA).bin`을 지정합니다. 패처가 크기·SHA-256·CRC32를 확인합니다.
3. **결과 폴더 선택**에서 빈 폴더를 지정하고 설치를 누릅니다. 패처가 BPS를 적용한 뒤 출력 BIN과 동봉 파일의 해시를 확인합니다. 실패하면 원본 BIN은 바뀌지 않습니다.
4. 결과 폴더에서 `Snatcher-KR-v0.776.bin`과 `Snatcher-KR-v0.776.cue`를 **함께 보관**합니다. RetroArch에서 게임을 열 때는 **`.bin`이 아니라 `.cue`**를 선택하세요. 이렇게 해야 CD 오디오 트랙 참조를 유지할 수 있습니다.
5. 사용하는 플랫폼에 맞는 **전용 코어**를 설치·선택하고 게임 `.cue`를 엽니다. 일반 코어로 열면 한국어 보이스 자막 기능이 빠집니다. BIOS는 RetroArch 안내에 따라 사용자가 별도로 설정해야 합니다.

### 플랫폼별 코어

| 플랫폼 | 전용 코어 파일 | 상태 |
| --- | --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` | 패처가 함께 출력합니다. Windows 실행·출력 해시 검증을 수행했습니다. |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` | 패처가 함께 출력합니다. APK는 수정하지 않습니다. 실제 Android 기기의 코어 로딩·게임 재생은 아직 미검증입니다. |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` | 패처가 함께 출력하고, 릴리스에서 단독으로도 받을 수 있습니다. Ubuntu 24.04 x86_64에서 빌드·ELF/의존성·동적 로드/libretro API 검사를 통과했습니다. 게임 재생은 미검증입니다. |

Windows에서는 출력된 DLL을 RetroArch의 사용자 코어 위치에 복사하거나 코어 파일을 직접 불러옵니다. Android에서는 출력된 ARM64 SO를 기기로 옮긴 뒤 기기 RetroArch에서 외부 코어 설치/가져오기 기능을 사용합니다. Linux에서는 Linux x86_64 SO와 같은 이름의 `.info`를 코어 및 코어 정보 위치에 두거나 해당 SO를 직접 불러옵니다. 버전·배포 방식에 따라 메뉴 이름과 코어 경로가 다를 수 있으므로 설치된 RetroArch의 안내를 확인하세요. Android용 SO를 Linux용으로, Linux용 SO를 Android용으로 바꿔 쓸 수는 없습니다.

패처는 게임 BIN/CUE, Windows DLL, Android ARM64 SO, Linux x86_64 SO, 코어 정보 `.info`, 코어·폰트 라이선스, 개조 코어의 전체 소스 ZIP과 빌드 기록을 한 폴더에 출력합니다. 원본 BIN, 기존 파일, RetroArch 설치본은 덮어쓰지 않습니다.

### Windows 없이 수동 적용하기

Linux/Android만 사용하는 사람을 위해 릴리스에 `Snatcher-KR-v0.776.bps`, 결과용 `Snatcher-KR-v0.776.cue`, 플랫폼별 전용 코어도 개별 자산으로 제공합니다. BPS 지원 패처에서 **위 해시의 원본 BIN → BPS → 새 결과 BIN** 순서로 적용하세요. 결과 BIN 이름을 `Snatcher-KR-v0.776.bin`으로 맞추고, 릴리스의 `Snatcher-KR-v0.776.cue`와 같은 폴더에 두세요. CUE 안의 `FILE` 지시문이 이 BIN을 가리킵니다. 결과 SHA-256이 아래 값과 일치해야 합니다. 이 경로에서는 전용 코어도 별도로 받아야 하며, 원본·결과 게임 자체는 릴리스에 없습니다.

**이전 버전 사용자도 원본에서 v0.776으로 다시 패치하세요.** 이미 수정된 BIN에는 덧씌울 수 없습니다. 새 BIN/CUE를 함께 사용하고, 구형 BIN에 새 CUE만 섞지 마세요. v0.775의 전용 r48 코어는 그대로 호환됩니다. 그보다 이전 코어라면 이번에 동봉된 r48로 교체하세요. 세이브스테이트에는 이전 메뉴 데이터가 남을 수 있으므로 게임을 재시작한 뒤 게임 내 저장으로 이어 하세요.

## 확인 범위와 알려진 제한

- 원본 FRONT5항목의 메뉴 참조와 주변 대사를 대조했습니다. 접수처 이동3항목만 고쳤고 나머지 방향2항목은 유지했습니다. 새 문구는 기존 빈 영역에 두고 메뉴 연결7개만 바꾸어, 기존 글자·폰트·음성 자산 주소가 이동하지 않도록 했습니다.
- 최종 게임의 실제 M68000 메뉴 등록·문구 복사 코드를 분리 실행해 **7개 연결 × 메뉴 위치6개 = 42조건**을 통과했습니다. “접수처”의 세 글자·종료 문자 복사 및 모듈 데이터 불변을 확인했습니다. 이는 게임 전체 장면을 재플레이한 결과가 아닙니다.
- 변경·설치·텍스트 편집기 관련 **자동시험33개** 통과. 전체265,813개 원시 섹터 중 변경9개만 대상3모듈 안에 있고, EDC/ECC가 유효하며 나머지265,804개(오디오 포함)는 이전판과 동일합니다. 파일 크기·디렉터리·트랙 배치도 그대로입니다.
- **최종 v0.776 EXE 자체**로 원본625,192,176바이트 BIN에 실제 패치를 적용했습니다. 결과11/11파일 크기/SHA-256/CRC32 일치, 원본 불변을 확인했습니다. BPS를 두 번 생성해 동일성과 독립 적용 검사를 통과했습니다.
- v0.775의 타이밍68쪽 교정·해리 누락 절 복원·추가 CD 자막427쪽을 그대로 포함합니다. 승인된 오프닝과 PCM 자막은 바꾸지 않았습니다. 해결된3인 초상화나 전편 플레이는 반복하지 않았습니다.
- 동봉 r48 코어의 Linux 소스 해시·빌드·ELF/의존성·동적로드/API1 확인은 [v0.775 빌드 기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/38495067876)을 그대로 잇습니다. 이번에 코어를 새로 빌드한 것으로 표시하지 않습니다. 소스ZIP과 CORE-BUILD/CORE-REPRODUCTION도 같은 파일입니다.
