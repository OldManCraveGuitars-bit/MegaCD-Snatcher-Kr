# v0.777 — 초반 미카 보이스 자막 존댓말 수정

초반 미카의 결혼 여부 질문(PCM92, SP06.BIN)을 **“결혼했지, 그렇지?” → “결혼하셨죠, 그렇죠?”**로 수정했습니다. 원문 `You're married, aren't you?`의 질문 의미와 확인 표현을 보존하면서 존댓말로 맞췄습니다.

**보이스 자막에는 이번 v0.777 전용 Genesis Plus GX 코어(r49)가 필요합니다.** 일반 코어는 보이스 자막을 표시하지 않으며, 이전 전용 코어에서는 이 문구가 바뀌지 않습니다. RetroArch 본체와 APK는 수정하지 않습니다.

## 변경 범위

- PCM 자막1,647쪽 중 해당1쪽만 교정했습니다. 다른1,646쪽·음성 재생 시간·전체 자막 시각·승인된 오프닝·회상·추가 CD 음성427쪽은 그대로입니다.
- 같은 글꼴과 하단 한 줄 배치, 흰 글자와 밀착 검은 테두리를 유지했습니다. 큰 검은 상자를 만들지 않습니다.
- 전용 코어의 해당 자막 글자 그림만 수정했습니다. 게임 BIN/BPS와 화면 합성 코드는 v0.776과 같습니다. 게임에 남아 있는 구형 자막 그림은 전용 코어가 표시하는 그림이 아닙니다.
- v0.776의 “접수처” 메뉴 수정도 포함합니다. 다른 대사의 말투를 다시 일괄 변경한 버전은 아닙니다.

## 업데이트 — v0.776 사용자는 코어만 교체

아래 출력 BIN 해시와 같은 **v0.776 게임을 사용 중이면 게임을 종료하고 플랫폼에 맞는 v0.777 전용 코어만 교체**하세요. 기존 BIN/CUE와 파일명은 그대로 사용할 수 있습니다. 새 CUE만 옛 이름의 BIN 옆에 두면 파일명 불일치로 열리지 않습니다.

v0.775 이하 또는 결과 BIN 해시가 다르면, 접수처 교정을 포함하기 위해 아래 방법으로 **미국판 원본에서 다시 패치**하세요. 이미 수정한 BIN에 덧씌우는 방식은 지원하지 않습니다. 저장 파일은 먼저 백업하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

1. `MegaCD-Snatcher-Kr-v0.777-Windows-Patcher.zip`을 풀고 `SnatcherKRInstaller.exe`를 실행합니다. 단독 EXE도 같은 파일입니다.
2. 아래 해시의 미국판 원본 `Snatcher (USA).bin`을 선택합니다.
3. 약700MB 이상 여유 공간이 있는, 이미 존재하는 빈 출력 폴더를 지정합니다. 원본과 기존 동명 파일은 덮어쓰지 않습니다.
4. 생성된 `Snatcher-KR-v0.777.bin`과 `Snatcher-KR-v0.777.cue`를 함께 두고 RetroArch에서 **CUE**를 엽니다.
5. 사용하는 플랫폼의 **r49 전용 코어**를 선택합니다. BIOS는 별도로 준비해야 합니다.

| 플랫폼 | 동봉 코어 |
| --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` |

Android SO와 Linux SO는 서로 호환되지 않습니다. Windows 없이 적용할 때는 BPS 지원 패처로 동일 원본에 `Snatcher-KR-v0.777.bps`를 적용하고 결과 이름을 `Snatcher-KR-v0.777.bin`으로 맞춰 동봉 CUE와 함께 사용하세요. 게임 BIN/BPS 바이트는 v0.776과 같고 CUE의 참조 파일명만 v0.777로 바뀝니다.

## 확인 범위

- 번역 입력·한 쪽만 변경하는 처리·잘못된 입력 거부·편집기·설치 관련 자동시험 **31개 통과**.
- 실제 생산 C 자막 처리 코드를 분리 실행하여 두 바이트순서에서 각각76프레임, 총152표시프레임을 확인했습니다. 음성 시작 전 비표시, 종료 시점76프레임, 조기 음성 종료 시 제거도 유지됩니다. 이는 원음의 새로운 타이밍 교정이 아니라 기존 표시 시각 보존 검사입니다.
- 변경 자막의 흰174·검정297픽셀 및 나머지 픽셀/RAM 불변을 확인했습니다. 다른 모든 자막 헤더 바이트와 시간표는 동일합니다.
- 코어 소스980파일 중 자막 자산 헤더1개만 바뀌고 나머지979파일은 동일합니다. Windows/Android/Linux 코어3종 모두 새 자막 그림을 정확히1개 포함하고 옛 그림은 포함하지 않는지 확인했습니다.
