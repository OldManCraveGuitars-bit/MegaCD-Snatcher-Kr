# V1.01 전환 정지 수정의 범위

V1.0에서 나폴레옹 통화 후 플라톤 동굴 앞 복귀 시 `SP11.BIN`의 스크립트 PC가 `$0404`에 남고 메뉴가 사라졌다. 북미 원본은 같은 게임 내 저장·입력으로 `$00BE` 메뉴에 복귀했다. 변경하지 않은 Windows 순정 GX와 r61 DLL 양쪽에서 V1.0 정지를 관측했다.

수정은 코어가 아니라 **게임 이미지의 공통 SUBCODE**에 적용한다. V1.0의 자막 호출 등록 포인터를 SP11에서만 비활성화한 진단판도 복귀했지만, 최종판은 모든 장소의 자막 데이터를 유지하며 공통 호출 경로를 고친다.

| 항목 | V1.0 | V1.01 |
| --- | --- | --- |
| PCM 시작 후크 파일 범위 | `$D200..$D299` | 동일 범위, 154바이트 |
| 동작 | 게임 텍스트 설명자 `$97CC/$97CE` 수정, CPU 상태 보존 불완전 | 게임 텍스트 설명자 쓰기 제거, SR·작업 레지스터 보존, 자막 전용 조회 상태 게시 |
| SAT/VBlank 등록 호출 파일 범위 | `$D396..$D3FD` | 동일 범위, 104바이트 |
| 호출 조건 | 모듈 등록이 유효하면 프레임마다 호출 | 실제 PCM 시작에서 게시한 pending이 있을 때만 호출 |
| 자막 페이지 시간·그림 | r61 코어의 기존 자료 | 바이트 동일 |

실제 차이는 SUBCODE 내부 **197바이트**, raw Mode1 LBA **51761 한 섹터**다. 변경 섹터의 EDC/ECC를 재계산했다. ISO 디렉터리·파일 길이와 나머지 **265,812섹터**는 동일하다. SP00..SP38의 스크립트·음성 등록·글꼴을 포함한 다른 ISO 파일은 모두 그대로다.

- V1.0 SUBCODE SHA-256: `49342db857f4e02b1c0c81a157e99273520be1152a0335150da2b80a92c54b77`
- V1.01 SUBCODE SHA-256: `c16dbc207cb2cb614bd878235c42c54030cd4c3ccf9a8a89027a40c88626976a`
- 적용 입력·결과 전체 BIN SHA-256 및 배포 파일은 [릴리스 기록](RELEASE-v1.01.md#입력출력-해시)을 참고한다.

후속 부품 통합 검사에도 두 후크가 옛 코드로 되돌아가지 않도록 차단 조건을 추가했다. 기존 완성 게임 파일·실행 메모리를 강제로 수정해 통과한 상태를 만드는 테스트는 사용하지 않았다. CPU 내부에서 멈춤으로 이어지는 모든 명령의 실행 궤적을 추적했다는 뜻은 아니며, 원본/문제판/수정판의 실제 실행 대조와 변경 범위 감사를 근거로 한다.

코어 소스 ZIP·Windows DLL·Android ARM64 SO·Linux x86_64 SO는 V1.0과 동일하다. 따라서 코어 재빌드나 새 플랫폼용 코어 추가는 이번 수정 범위에 없다. Linux 장치 직접 플레이와 모든 게임 분기 완주는 별도 미검증 사항이다.
