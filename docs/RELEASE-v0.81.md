# v0.81 — 나폴레옹 이름과 조던 영문 암호 힌트 보완

2026-10-19. **음성과 함께 표시되는 한국어 보이스 자막에는 전용 Genesis Plus GX 코어가 필요합니다.** 이번에는 게임 본문을 수정했으며, 동봉 코어는 v0.778/v0.8과 같은 r50입니다. RetroArch 본체나 APK는 수정하지 않습니다.

## 반영 내용

- **‘나폴레옹에 대하여’의 모든 반복·조건별 대사에 `나폴레옹(NAPOLEON)`을 명시**했습니다. 원본 전체 스크립트에서 해당 메뉴6곳을 확인하여 연결 대사29개를 반영했습니다. 상대의 답변뿐 아니라 그 사이에 있는 길리언의 되묻기·응답도 포함합니다.
- 대상은 국장·미카·해리·카트리나·나폴레옹과의 대화입니다. 원래 인물이 아니라 브랜디, 의상, 역사적 인물을 말하는 답변도 있어 그 의미를 유지했습니다. 해당 질문 밖에 있는 모든 나폴레옹 언급을 일괄 치환한 것은 아닙니다.
- 조던의 나폴레옹 정보2항목에 `나폴레옹(NAPOLEON) 보나파르트`, **`백일천하(100 day REIGN)`**, **`혁명은 끝났다. (IS ENDED)`**를 표시합니다. IS ENDED는 원문의 혁명 인용구에 붙고, REIGN은 백일천하 설명에 붙습니다. 실제 정답 입력 비교 키는 그대로입니다.
- v0.8 대비 **31/10,728본문 수정**, 나머지10,697항목 유지. v0.8의 `깁슨(GIBSON)`·`카트리나(KATRINA)`, `허벅지(THIGH)`·`하트(HEART) 모양 반점(BIRTHMARK)`, `위로하기` 수정도 모두 유지합니다.
- **보이스 자막·음성·시간표·오프닝·렌더러·전용 코어3종 변경 없음.** 재채기 `에.. 에취!`, 미카 존댓말, `접수처`도 그대로입니다. 코어 소스·라이선스·빌드 기록을 동일하게 재사용하며, 기록 안의 v0.778은 해당 코어의 실제 제작 버전입니다.

예시:

> 나폴레옹(NAPOLEON)이라... 모르겠군... 요즘은 어디서든 정보를 구할 수 있으니 그런 정보상은 믿지 않네...

전체 본문·보이스 문맥 재검수는 별도 미완료 작업입니다. 이번31항목 수정 완료를 전편 새 검수 완료라고 표시하지 않습니다.

## 패처 사용법

1. `SnatcherKRInstaller.exe` 또는 `MegaCD-Snatcher-Kr-v0.81-Windows-Patcher.zip`을 받습니다. ZIP에는 같은 EXE와 설명·라이선스가 들어 있습니다.
2. 본인이 보유한 **미국판 원본 `Snatcher (USA).bin`**을 선택합니다. 아래 크기·SHA-256·CRC32와 일치해야 합니다. 다른 판본이나 이미 패치한 BIN은 거부합니다.
3. 약700MB 이상 여유가 있는 **기존의 빈 폴더**를 출력 위치로 선택합니다. 새 게임 BIN/CUE, Windows DLL·Android ARM64 SO·Linux x86_64 SO, 코어 정보, 소스·라이선스·빌드 기록을 출력합니다. 원본이나 기존 파일을 덮어쓰지 않습니다.
4. `Snatcher-KR-v0.81.bin`과 `Snatcher-KR-v0.81.cue`를 함께 보관하고 **전용 코어로 CUE를 실행**합니다. BIN만 열지 마세요. BIOS는 별도로 준비해야 합니다.

**v0.8 이하 사용자는 원본에서 v0.81로 다시 패치해야 합니다.** 기존 r50 코어는 그대로 사용할 수 있습니다. 더 오래된 코어는 동봉된 플랫폼별 파일로 교체하세요. 게임만 패치하고 일반 코어를 쓰면 보이스 자막 기능이 빠집니다.

저장 파일은 먼저 백업하세요. 이전 세이브스테이트에는 옛 대사 메모리가 남을 수 있으므로 게임을 완전히 재시작하고 **게임 내 저장을 불러온 뒤 해당 장소에 재진입**하는 방식을 권장합니다. 파일명이 바뀌어 저장이 보이지 않으면 원래 저장을 보존하고 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

Windows 없이 적용하려면 BPS 지원 패처로 원본에 `Snatcher-KR-v0.81.bps`를 적용하고 결과 이름을 `Snatcher-KR-v0.81.bin`으로 맞추세요. 제공 CUE와 같은 폴더에 두고 플랫폼별 전용 코어를 별도로 받습니다. Android SO와 Linux SO는 서로 호환되지 않습니다. 플랫폼별 설치 설명과 기존 화면 예시는 [README](../README.md)에 있습니다.

## 확인 범위

- **자동시험135/135 통과.** 답변29개 각각의 이름 누락 거부, 메뉴 등록 목록 변경 거부, 조던 영문 힌트 문맥·제어코드·기존 수정 보존, 본문 인코딩·편집기·설치 입력 검증 등을 포함합니다.
- 설치된 M68000 대사 읽기 루틴을 분리 실행해 **31항목130구간**을 검사했습니다. 기존 위로하기/접수처 메뉴48경우도 통과했습니다. 실제 게임 장면 재생과는 구분합니다.
- v0.8 대비 전체265,813섹터 중14섹터만 변경. 다른 섹터·기존 글꼴/본문/음성 주소를 유지하고 ISO 길이 필드·CUE 구조·변경 섹터 EDC/ECC를 확인했습니다. 기능성 입력키178개 보존, SP18/SP35 정답 모듈 및 SP06 기존 소개 모듈은 전체 바이트 동일합니다.
- BPS2회 생성 결과 동일, 모든 적용 동작·원본/결과/패치 CRC·목표 바이트 대조 통과.
