# v0.778 — 폐공장 재채기 보이스 자막 교정

폐공장 막다른 길에서 길리언의 재채기를 비명처럼 표시하던 두 자막을 사용자 제보에 따라 **“에.. 에취!”**로 수정했습니다.

| 음성 ID | 이전 자막 | 수정 자막 |
| --- | --- | --- |
| PCM165 / SP07.BIN | 헉... 으아아악! | 에.. 에취! |
| PCM166 / SP07.BIN | 으아아악! | 에.. 에취! |

**수정된 보이스 자막에는 v0.778 전용 Genesis Plus GX 코어(r50)가 필요합니다.** 일반 코어는 보이스 자막을 표시하지 않으며, 이전 전용 코어에서는 이 수정이 적용되지 않습니다. RetroArch 본체와 APK는 수정하지 않습니다.

## 수정 범위

- 사용자 제보와 원본 SP07의 음성 호출·인접 막다른 길 대사를 대조해 위2항목을 특정했습니다. 기존 기계 전사의 비명 분류를 그대로 신뢰하지 않고 재채기 표기로 바로잡았습니다. 새로운 독립 청취나 전편 재검수를 수행했다는 뜻은 아닙니다.
- 전체 PCM 자막1,647쪽 중2쪽만 수정하고 나머지1,645쪽은 그대로입니다. 다른 장면의 실제 비명 자막과 PCM164는 바꾸지 않았습니다.
- 두 자막의 시작·종료 시각은 그대로입니다. 음성165의 기존 종료159프레임,166의219프레임을 유지했습니다. 음성 파일·오프닝·회상·추가 CD 자막427쪽도 불변입니다.
- 동일 글꼴·하단 한 줄·흰 글자와 밀착 검은 테두리를 유지합니다. 화면 합성 코드나 게임 BIN/BPS는 변경하지 않았습니다.
- v0.777의 미카 “결혼하셨죠, 그렇죠?”와 v0.776의 “접수처” 수정도 그대로 포함합니다.

## 업데이트 — v0.776/v0.777 게임은 코어만 교체

아래 출력 BIN 해시와 같은 **v0.776 또는 v0.777 게임을 사용 중이면 게임을 종료하고 v0.778 r50 전용 코어만 교체**하세요. 기존 BIN/CUE와 파일명은 그대로 쓸 수 있습니다. 새 CUE만 이전 이름의 BIN 옆에 섞으면 파일명 불일치로 열리지 않습니다.

v0.775 이하 또는 결과 BIN 해시가 다르면 접수처 교정까지 포함하기 위해 미국판 원본에서 다시 패치하세요. 수정된 BIN에 덧씌우는 방식은 지원하지 않습니다. 저장 파일은 먼저 백업하고 게임을 재시작하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

1. `MegaCD-Snatcher-Kr-v0.778-Windows-Patcher.zip`을 풀고 `SnatcherKRInstaller.exe`를 실행합니다. 단독 EXE도 같은 파일입니다.
2. 아래 해시의 원본 `Snatcher (USA).bin`을 선택합니다.
3. 약700MB 이상 여유 공간이 있는, 이미 존재하는 빈 출력 폴더를 지정합니다. 원본과 기존 동명 파일은 덮어쓰지 않습니다.
4. 결과 `Snatcher-KR-v0.778.bin`과 `Snatcher-KR-v0.778.cue`를 함께 보관하고 RetroArch에서 **CUE**를 엽니다.
5. 플랫폼에 맞는 **r50 전용 코어**를 선택합니다. BIOS는 별도로 준비하세요.

| 플랫폼 | 동봉 코어 |
| --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` |

Android SO와 Linux SO는 서로 호환되지 않습니다. Windows 없이 적용하려면 BPS 지원 패처로 동일 원본에 `Snatcher-KR-v0.778.bps`를 적용하고 결과를 `Snatcher-KR-v0.778.bin`으로 이름 붙여 동봉 CUE와 함께 사용하세요. BIN/BPS 바이트는 v0.776/v0.777과 같으며 CUE의 참조 파일명만 새 버전에 맞췄습니다.
