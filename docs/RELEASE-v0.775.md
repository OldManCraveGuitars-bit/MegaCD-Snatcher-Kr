# v0.775 — 신규 보이스 자막 타이밍 교정·누락 대사 보완

**음성을 따라가는 한국어 보이스 자막 패치입니다. 수정 사항을 적용하려면 v0.775 전용 Genesis Plus GX 코어(r48)로 교체해야 합니다.** Windows x86_64 DLL, Android ARM64 SO, Linux x86_64 SO를 함께 제공합니다. RetroArch 본체와 APK는 수정하지 않습니다.

## 이번 수정

v0.77에서 추가한 **13개 CD 음성 트랙·기존 426쪽 전체**의 시작·끝·전환을 원음 기준으로 대조해 **68쪽의 타이밍을 수정**했습니다. 늦게 나타나는 첫마디, 덜 끝났는데 바뀌는 자막, 다음 화자와 겹치는 표시를 조정했습니다. 숫자는 표시 페이지 수이며 문장 수가 아닙니다.

확인 중 해리의 “난 살아남지 못할 거라는 걸 알아.”에 해당하는 절이 빠진 것도 발견했습니다. 서로 다른 크기의 무힌트 음성 전사에서 같은 절을 확인하고, 다음 “자네는 착한 친구였어, 길리언.”과 분리해 두 쪽으로 복원했습니다. 따라서 추가 CD 자막은 **426쪽 → 427쪽**입니다. 타이밍 교정68쪽과 별도로 내용 보완1쪽이 있으며, 나머지 기존425쪽의 영어·한국어 문구와 글자 그림은 그대로입니다.

아래 시각은 각 CD 트랙 시작을 0초로 한 자막 표시 시점입니다. 게임 실행 전체 경과 시각이나 기계 분석의 정밀도 보증이 아닙니다. 후반 대사의 일부가 포함됩니다.

## 확인 방식과 범위

- 독립 wav2vec2 CTC 문자/단어 정렬과 Whisper large-v3 참조 정렬을 각각 **426/426쪽**에 수행했습니다. 13트랙 전체의 무힌트 전사와 짧은 예외 구간 전사를 함께 대조했습니다.
- 불확실 후보39건 및 말머리·반복·긴 문장 전환을 따로 검토했습니다. 영어 참조가 축약된 곳의 한 단어 피크를 발화 시작으로 삼아 접속어·호명·머뭇거림을 잘라 버리는 후보는 제외했습니다. 두 정렬 방식이 다르더라도 무조건 평균값을 적용하지 않았습니다.
- 최종427쪽을 컴파일한 실제 C 자막 소비처로 **13트랙151,169섹터**에 걸쳐 검사했습니다. 페이지 경계·두 픽셀 바이트순서·재생 중지/탐색/음소거 등9비활성조건·흰 글자/검은 테두리/투명 영역·게임RAM 불변을 확인했습니다. 관련 **표적 자동시험26개 통과**.
- **최종 EXE 자체**로 원본625,192,176바이트 BIN에 패치를 적용했습니다. 결과 **11/11파일**의 크기·SHA-256·CRC32가 일치하고 원본은 불변입니다. 패처의 실제 CLI 실행 검사이며 GUI를 직접 관찰한 검사로 확대하지 않습니다.
- Windows r48의 새 부팅 후 완료 프레임630까지 짧은 실행을 확인했습니다. 입력·스테이트 로드·게임 메모리 주입·디스크 변경은 없었습니다. 새 대사 전체를 게임에서 재플레이했다는 뜻은 아닙니다.
- Linux x86_64는 [Actions 38495067876](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/38495067876)에서 소스 해시·빌드·ELF/의존성·동적 로드/libretro API1 검사를 통과했습니다. Android ARM64 빌드도 완료했습니다.

원음 기반 기계 정렬과 문맥 대조는 수행했지만, 모든 대사를 사람이 직접 듣고 승인한 것은 아닙니다. 호흡·머뭇거림의 미세 경계에는 분석 오차가 있을 수 있습니다. Android 기기 실사용, Linux 실제 게임 재생, 실기 Mega CD 및 모든 분기 플레이는 미검증입니다.

## 바꾸지 않은 것

- **승인된 오프닝 타이밍**, 기존 PCM 자막과 Track03/04/08/09, 회상, 본문·선택문, 말투 교정, 제이미 이별의 “잘 안 들려!” 복원은 그대로입니다.
- 처음 폐허로 가는 Track20 독백4쪽과 Track18의 시각도 유지했습니다. 첫 폐허 독백은 v0.77의 정상 경로 실행에서4/4 실제 표시·음성 정렬을 확인한 이력이 있습니다. 기존 화면은 [README 갤러리](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.775/README.md#화면-예시)에 출처와 함께 보존했습니다. r48의 새 촬영본으로 표시하지 않았습니다.
- 하단 흰 글자·밀착 검은 테두리를 그리는 **최종 화면 합성 코드 자체는 바꾸지 않았습니다.** 음성 재생 시계를 따르며 자막 외 영역은 투명합니다. 이미 해결한 3인 초상화 반복검사는 하지 않았습니다.
- **게임 BIN/BPS는 v0.76·v0.77의 r251과 동일합니다.** 이번 변경은 코어의 자막 시각·해리 대사 자산과 패키지 이름입니다.

## 설치·업데이트

### v0.76 또는 v0.77 사용 중

아래 한국어 결과 BIN 해시가 맞으면 **게임 재패치 없이 v0.775 전용 코어만 교체**하세요. 게임을 종료하고 플랫폼에 맞는 r48 코어를 설치한 뒤 기존 BIN/CUE로 다시 실행하면 됩니다. 기존 BIN/CUE 파일명은 유지할 수 있습니다. 새 v0.775 CUE만 기존 이름의 BIN 옆에 놓으면 파일명이 달라 열리지 않습니다.

기존 세이브스테이트 호환성은 보증하지 않으므로 가능한 게임 내 저장으로 이어 하세요. 기본 코어에는 보이스 자막 기능이 없고, 구형 전용 코어에는 이번 수정이 없습니다.

### 신규 설치 또는 v0.75에서 업데이트

1. `MegaCD-Snatcher-Kr-v0.775-Windows-Patcher.zip`의 압축을 풀어 `SnatcherKRInstaller.exe`를 실행합니다. 단독 EXE도 같은 프로그램입니다.
2. 아래 해시와 일치하는 미국판 **원본 BIN**을 선택합니다. 이미 수정된 BIN에 덧씌우지 않습니다.
3. 약700MB 이상 여유가 있는 **기존의 빈 출력 폴더**를 선택합니다. 패처는 입력 원본과 동명 파일을 덮어쓰지 않습니다.
4. 패치와 해시 검사가 끝나면 한국어 BIN/CUE, 코어3종, 코어 정보, 라이선스2종, 전체 개조 코어 소스 ZIP과 빌드 기록이 출력됩니다.
5. 플랫폼에 맞는 전용 코어를 설치하고 **BIN이 아닌 CUE**를 RetroArch에서 여세요. BIOS는 사용자가 별도로 준비합니다.

| 플랫폼 | 사용할 코어 |
| --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` |

Android SO와 Linux SO는 서로 바꿔 쓸 수 없습니다. APK를 빌드하거나 수정하지 않습니다. 외부 코어 설치 방법은 각 RetroArch 배포판의 안내를 따르세요.

Windows 없이 적용할 때는 BPS 지원 패처로 원본에 `Snatcher-KR-v0.775.bps`를 적용하고, 결과 BIN을 `Snatcher-KR-v0.775.bin`으로 이름 붙여 같은 릴리스의 CUE와 함께 두세요. 플랫폼별 전용 코어도 따로 받아야 합니다. 자세한 설치 절차와 화면 예시는 [README](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.775/README.md)에 있습니다.
