# v0.95 — 말투·힌트 표기 교정 및 해리 장면 누락 보이스 자막 복원

2026-10-23. **한국어 보이스 자막에는 동봉된 전용 Genesis Plus GX r57 코어가 필요합니다.** 게임 문구와 코어 속 자막을 함께 수정한 판입니다. **v0.9 이하 사용자는 미국판 원본에서 다시 패치하고, 사용하는 플랫폼의 코어도 교체하세요.** RetroArch 본체/APK는 수정하지 않습니다.

## 반영 내용

- **해리 장면의 누락 자막 한 문장을 추가했습니다.** 메탈기어의 `Gillian, he's about...`를 `길리언, 이분은 곧...`으로 표시합니다. CD12 185.86–187.80초입니다. 원음의 말을 흐리는 표현을 유지하며, 말하지 않은 뒷말을 창작하지 않았습니다. 앞뒤 해리의 대사는 그대로입니다.
- **길리언→메탈기어 반말 / 메탈기어→길리언 존댓말** 혼용 사례를 교정했습니다. ACT 2 아파트의 `이번에는 저도 들립니다`→`이번에는 나도 들려`, 메탈의 `뭔가 들려`→`뭔가 들립니다`, 제이미 통화 중 메탈의 `틀림없어, 길리언`→`틀림없습니다, 길리언`, 터보사이클 탈출의 `네! 네! 뭐든 누르십시오!`→`그래! 그래! 뭐든 눌러!` 등이 포함됩니다. 다른 인물·집단을 향한 적절한 존댓말은 유지했습니다.
- **랜덤의 존댓말 잔여를 반말로 교정**했습니다. 병원 장치 설명의 `한 사람이 미쳐서 독단적으로 행동할 위험을 막는 장치입니다`는 `…장치야`로 바꿨고, 앞선 설명도 통일했습니다.
- 기억 관련 질문 메뉴의 **`메모리`를 `기억`으로 수정**했습니다.
- 번역 문구·자막에 표시되는 **영문을 대문자로 통일**했습니다. `OLEEN/OLEENS/OLEENA`, `QUEEN/QUEENS`, 영문 퍼즐 힌트 등을 포함합니다. 원문 증거·코드·제어 토큰·실제 정답 입력 판정키·원본 그림을 일괄 대문자로 바꾼 것은 아닙니다.
- 원소 퍼즐 본문6곳과 보이스4곳에 **`베릴륨(BE)`, `질소(N)`, `황(S)`, `산소(O)`**를 넣었습니다. 반복 질문과 두 원소 순서 설명, `BENSON` 해독을 보존했습니다. `BE`는 게임 내 대문자 표시 규칙입니다.
- 기존 미카·국장 말투, `접수처`, `위로하기`, `에.. 에취!`, 나폴레옹·깁슨·카트리나의 영문 힌트도 유지합니다.

추가 CD 음성 자막은 **427→428쪽**입니다. 기존427쪽은 위의 말투 수정 외에 시간표·순서를 보존했습니다. 새 한 문장의 구간만 추가했고 기존 PCM·오프닝·회상의 시각, 원음, 음성 동기 처리 및 **하단 흰 글씨·검은 테두리** 렌더러 코드는 변경하지 않았습니다. 메탈기어가 잠깐 말하는 미완성 문장을 이전 검수에서 놓쳤으며 이번에 복원한 것입니다. 전편 누락이 전혀 없다고 보증하지 않습니다.

## 패처 사용법

1. `SnatcherKRInstaller.exe` 또는 `MegaCD-Snatcher-Kr-v0.95-Windows-Patcher.zip`을 받습니다. ZIP에는 같은 EXE와 설명·라이선스가 있습니다. 패처는 **Windows 64비트용**입니다.
2. 본인이 보유한 미국판 원본 `Snatcher (USA).bin`을 선택합니다. 아래 크기·해시와 정확히 일치해야 하며, 이미 패치한 BIN이나 다른 덤프는 거부합니다.
3. 약700MB 이상 여유가 있는 **기존의 빈 폴더**를 결과 위치로 지정합니다. 원본·기존 파일을 덮어쓰지 않습니다.
4. 출력된 `Snatcher-KR-v0.95.bin`과 `Snatcher-KR-v0.95.cue`를 함께 보관합니다. 새 전용 코어를 설치·선택한 뒤 **BIN이 아니라 CUE**를 실행하세요. BIOS는 별도로 준비합니다.

| 플랫폼 | 전용 코어 |
| --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` |

패처는 게임 BIN/CUE와 위 코어3종, `.info`, 라이선스, 전체 개조 코어 소스 ZIP·빌드 기록을 출력합니다. **Android APK를 만들지 않으며, Android와 Linux의 SO는 서로 다른 파일입니다.** 일반 코어만 쓰면 보이스 자막이 표시되지 않습니다.

**v0.9 이하에서 올릴 때는 게임 재패치와 코어 교체가 모두 필요합니다.** 패치된 BIN에 덧씌우지 말고 원본에서 새 빈 폴더에 적용하세요. 게임만 교체하면 이전 보이스 자막이 남고, 코어만 교체하면 새 메뉴·힌트 표기가 반영되지 않습니다.

저장 파일은 먼저 백업하세요. 이전 세이브스테이트에는 수정 전 대사 데이터가 남아 있을 수 있으므로 게임을 완전히 다시 실행한 뒤 **게임 내 저장을 불러오고 해당 장소에 재진입**하는 방법을 권장합니다. 파일명이 바뀌어 저장을 못 찾으면 원래 저장을 보존한 채 RetroArch의 저장 이름/경로를 확인하세요. 모든 세이브스테이트 호환성을 보증하지 않습니다.

Windows 없이 적용하려면 BPS 지원 패처로 원본에 `Snatcher-KR-v0.95.bps`를 적용하고 결과를 `Snatcher-KR-v0.95.bin`으로 저장합니다. 제공 CUE와 같은 폴더에 두고 아래 결과 해시를 확인한 뒤 플랫폼별 r57 코어를 받으세요. 자세한 설치 설명·기존 촬영 화면은 [README](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.95/README.md), 추가 화면은 [오프닝 갤러리](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.95/docs/OPENING-GALLERY.md)에 있습니다. 기존 스크린샷을 v0.95 신규 촬영이라고 표시하지 않았습니다.

## 확인한 범위와 한계

- 이번 배포 표적 **자동시험51/51 통과**. 설치기, 원소 힌트, 길리언/메탈/랜덤 교정, 해리 누락 및 실제 C 자막 선택기 검사를 포함합니다.
- 원소 본문6항목의 M68000 읽기22구간, 영문 대문자 본문33항목의 읽기110구간 및 입력 키184개 보존은 해당 로컬 수정 때 확인했습니다. 이전 완료 검사를 이번 새 게임 플레이 결과로 표현하지 않습니다.
- BPS2회 생성 결과 일치와 전체 패치 적용 동작·CRC·목표 바이트 대조를 확인했습니다.
- 최종 배포 EXE를 원본625,192,176바이트 BIN에 실제 적용해 **출력11/11파일**의 크기·SHA-256·CRC32 일치와 원본 불변을 확인했습니다. GUI 관찰이나 게임 플레이 시험과는 구분합니다.
- 실제 제품 C 자막 선택/합성 코드에서 추가CDDA 13트랙·428쪽의 모든 섹터, 페이지 잉크, 정지/탐색/음소거·비대상 영역·게임RAM 보존을 검사했습니다. 신규 문장은 원음의 새 무힌트 기계 전사2종과 기존 전사를 대조했습니다. 사람 청취 승인은 아닙니다.
- Windows DLL 로드/API1, Android ARM64 ELF와9필수 libretro exports, Linux ELF/동적 로드/API1을 확인했습니다. [Linux 빌드 기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/39833394506). Android는 NDK r30/API21, Linux는 Ubuntu24.04 x86_64로 빌드했습니다.
- 코어3종 모두 **33개 전체 자막 비트맵 은행**을 동일하게 포함합니다. 소스980파일 중 v0.9와 달라진 것은 자막 헤더1개이고979개는 그대로입니다. 전체 대응 소스 ZIP SHA-256: `5b249211bf8a45c6652fe1268f1a0319dc40e62b9713eea05749bdaba43772dd`.
- 새 전편 플레이·전체 인물 전수 검수·전편 청취·Android/Linux 실제 게임·실기 검증은 하지 않았습니다. 본 배포물은 **메가CD용 패치와 libretro 코어**이며 NDS 실행 파일은 포함하지 않습니다.
