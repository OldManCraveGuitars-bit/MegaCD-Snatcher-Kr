# v0.9 — 메탈기어·국장 말투 교정 및 전용 코어 갱신

2026-10-22. **한국어 보이스 자막에는 동봉된 전용 Genesis Plus GX r52 코어가 필요합니다.** 이번에는 게임 본문과 코어 속 자막을 함께 수정했습니다. **미국판 원본에서 게임을 다시 패치하고 Windows·Android·Linux 중 사용하는 플랫폼의 코어도 반드시 교체하세요.** RetroArch 본체나 APK는 수정하지 않습니다.

## 반영 내용

- **메탈기어 본문4곳·보이스 자막22등록**의 반말 혼용을 존댓말로 교정했습니다. 설명·질문·감탄의 성격은 유지하며 원문 의미를 축약하지 않았습니다. 예: `병원 복도야` → `병원 복도입니다`, `그건 수사 경비인데` → `그건 수사 경비인데요`.
- **ACT 2 회상 전체55문구**를 원문과 대조하고 국장 설명27문구를 `~했네/~했지/~일세` 계열로 교정했습니다. `두 분은 … 향했습니다` → `자네와 메탈은 … 향했지`, 리사·프레디 관련 두 곳의 `당신이 … 처치했습니다` → `자네가 … 처치했지`. 원문에서 처치한 사람은 길리언이며 주체를 다른 인물로 바꾸지 않았습니다.
- 국장의 직접 본문336개와 관련 보이스 장면138등록도 대조했습니다. 관련 장면에는 다른 인물의 응답이 포함됩니다. 메탈의 회상 보고와 길리언이 국장에게 말하는 존댓말은 유지했습니다. 화자 구분 없이 어미를 일괄 치환하지 않았습니다.
- **원음과 자막 시간표는 변경하지 않았습니다.** 메탈 수정은27그림 페이지, 국장 회상 수정은30그림 페이지에 반영됩니다. 회상 전체75쪽의 시작·끝 시각과 페이지 경계는 그대로입니다. 오프닝·추가 CD 음성 자막·엔딩·렌더러·음성 동기 처리 코드도 유지합니다.
- Windows DLL·Android ARM64 SO·Linux x86_64 SO를 **같은 r52 자막 소스**로 갱신했습니다. 기존 r50 코어에는 이번 보이스 교정이 없습니다. 하단 흰 글씨·검은 테두리 표시 방식은 유지합니다.
- v0.81의 `나폴레옹(NAPOLEON)`, `백일천하(100 day REIGN)`, `끝났다. (IS ENDED)`와 이전 깁슨·카트리나 영문 힌트, `위로하기`, 재채기 `에.. 에취!`, 미카 존댓말, `접수처` 교정도 포함합니다.

### 정확한 수정 범위

- 본문: SP14/0332, SP15/0100, SP33/0192, SP35/0375. v0.81의10,728본문 중4개만 변경했습니다.
- 메탈기어 보이스 ID: 218, 280, 282, 284, 288, 332, 353, 400, 404, 427, 506, 510, 512, 571, 578, 601, 652, 676, 682, 759, 921, 1169. 전체1,130등록 중22변경/1,108유지입니다. 인접한 길리언의 응답인281/283/285/333 등을 자동으로 존대 처리하지 않았습니다.
- 국장 회상 단위: 5–15, 19–34. 메탈 보고3/4/40/41과 길리언 응답38/39/47은 유지했습니다.

이는 요청한 메탈기어·국장 교정 범위입니다. **모든 등장인물의 전 대사 재검수를 끝냈다는 뜻은 아닙니다.** 기존 판의 수정사항을 보존하면서 이번 변경에 필요한 검사만 진행했습니다.

## 패처 사용법

1. `SnatcherKRInstaller.exe` 또는 `MegaCD-Snatcher-Kr-v0.9-Windows-Patcher.zip`을 받습니다. ZIP에는 같은 EXE와 설명·라이선스가 들어 있습니다. 패처는 **Windows 64비트용**입니다.
2. 본인이 보유한 **미국판 원본 `Snatcher (USA).bin`**을 선택합니다. 아래 크기·SHA-256·CRC32와 일치해야 합니다. 다른 덤프·다른 리전·이미 패치한 BIN은 거부합니다.
3. 약700MB 이상 여유가 있는 **기존의 빈 폴더**를 출력 위치로 선택하고 설치합니다. 원본이나 기존 파일을 덮어쓰지 않습니다. 새 게임 BIN/CUE, 코어3종, 코어 정보, 전체 소스·라이선스·빌드 기록을 출력합니다.
4. `Snatcher-KR-v0.9.bin`과 `Snatcher-KR-v0.9.cue`를 함께 보관합니다. 아래 플랫폼별 **새 r52 전용 코어**를 설치·선택하고 **CUE를 실행**하세요. BIN만 직접 열지 마세요. BIOS는 별도로 준비해야 합니다.

| 플랫폼 | 선택할 전용 코어 |
| --- | --- |
| Windows x86_64 | `genesis_plus_gx_snatcher_kr_libretro.dll` |
| Android ARM64 | `genesis_plus_gx_snatcher_kr_libretro_android.so` |
| Linux x86_64 | `genesis_plus_gx_snatcher_kr_libretro.so` |

**v0.81 이하 사용자는 게임 재패치와 코어 교체가 모두 필요합니다.** 코어만 교체하면 새 본문4곳은 반영되지 않고, 게임만 패치하면 수정 전 보이스 자막이 남습니다. 일반 코어에는 보이스 자막 기능이 없습니다. Android SO와 Linux SO는 서로 바꿔 쓸 수 없습니다.

저장 파일은 먼저 백업하세요. 이전 세이브스테이트에는 옛 대사 메모리가 남을 수 있으므로 게임을 완전히 재시작하고 **게임 내 저장을 불러온 뒤 해당 장소에 재진입**하는 방식을 권장합니다. 게임 파일명이 바뀌어 저장이 보이지 않으면 원래 저장을 보존한 채 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지는 않습니다.

Windows 없이 적용하려면 BPS 지원 패처로 위 원본에 `Snatcher-KR-v0.9.bps`를 적용하고 결과를 `Snatcher-KR-v0.9.bin`으로 저장하세요. 제공 CUE와 같은 폴더에 두고 결과 해시를 확인한 뒤 플랫폼별 r52 코어를 별도로 받습니다. APK는 만들거나 수정하지 않습니다. 상세 설치 설명·기존 화면 예시는 [README](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.9/README.md), 추가 화면은 [오프닝 갤러리](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/blob/v0.9/docs/OPENING-GALLERY.md)에 있습니다. 스크린샷의 실제 촬영 버전은 각 설명을 따릅니다.

## 확인 범위

- 최종 교정 관련 **자동시험96/96**, 배포 준비 단계의 설치기·문구·편집기 관련 **57/57** 통과. 일부 중복되므로 독립 항목처럼 합산하지 않습니다.
- 설치된 M68000 대사 읽기 루틴에서 수정 본문4항목/10구간 검사. v0.81 대비 전체265,813섹터 중10섹터만 변경했으며 다른 섹터·기존 글꼴/본문/음성 주소·ISO/CUE 구조·변경 섹터 EDC/ECC를 확인했습니다.
- BPS2회 생성 결과 동일, 모든 적용 동작·원본/결과/패치 CRC·목표 바이트 대조 통과.
- **배포할 최종 EXE 자체**로 원본625,192,176바이트 BIN에 실제 적용했습니다. `--verify`/`--install` 성공, **출력11/11파일**의 크기·SHA-256·CRC32 일치, 원본 불변 확인. GUI 관찰 시험과는 구분합니다.
- 실제 제품의 C 자막 소비·합성 코드를 분리 실행해 회상75/75쪽의 시작·끝, 양쪽 바이트 순서, 정지/탐색/음소거를 검사했습니다. 흰 글씨26,538픽셀·검정 윤곽41,924픽셀, 비잉크 영역과 게임RAM 불변을 확인했습니다. 이는 게임 장면 전체 재생 결과는 아닙니다.
- Windows DLL 로드, Android ARM64 ELF와9필수 libretro exports, Linux ELF/의존성/동적 로드·API1을 확인했습니다. [이번 Linux Actions 실행](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/39643342748)은 고정된 r52 소스 ZIP으로 Ubuntu24.04에서 빌드했습니다. Android는 NDK r30/API21로 빌드했습니다.
- 3종 코어 모두 메탈 변경27그림과 회상75쪽의 최종 자산 포함 여부를 검사했습니다. 전체980소스 중 이전판과 달라진 것은 자막 그림 헤더1파일이며 나머지979파일은 같습니다. 전체 대응 소스와 라이선스·재현 명령을 동봉합니다. 소스 ZIP SHA-256: `863cd31221439d4aa5747e7303262592d684362b3acb09be347c9fd360adf782`.
- 새 전편 플레이·전체 인물 재검수·전편 청취·Android/Linux 실제 게임·실기 검증은 하지 않았습니다. 이미 해결된3인 초상화 반복 재생은 생략했고, 기존 화면 자료는 실제 촬영 버전을 표시해 보존했습니다.
