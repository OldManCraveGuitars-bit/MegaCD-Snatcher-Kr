# v0.8 — 소개·퍼즐 힌트 영문 병기와 행동 메뉴 교정

2026-10-18. **음성 진행에 맞춰 나오는 한국어 보이스 자막에는 전용 Genesis Plus GX 코어가 필요합니다.** 일반 코어에서는 해당 자막 기능을 사용할 수 없습니다. 이번 버전은 게임 본문 수정이며 전용 코어는 v0.778의 r50을 그대로 동봉합니다.

## 변경 사항

- 깁슨·카트리나의 초반 본부 소개를 반복해서 질문할 때 나오는 답변9개 모두에 해당 이름과 영문 철자를 넣었습니다. 관련 소개7개와 조던 프로필2개까지 합쳐18항목입니다. `깁슨(GIBSON)`, `카트리나(KATRINA)`를 확인할 수 있습니다.
- 조던에서 KATRINA를 조회하면 `허벅지(THIGH)`, `하트(HEART) 모양 반점(BIRTHMARK)`이 나옵니다. 이전 `모반` 표기는 바꾸고 퍼즐에 필요한 영문 철자를 제공합니다. 실제 정답 입력 키는 변경하지 않았습니다.
- 미카·카트리나 대화의 행동 항목 `콘솔`을 **`위로하기`**로 고쳤습니다. 원문의 CONSOLE은 기계를 뜻하는 명사가 아니라 상대를 위로하는 동사입니다. 본문2항목/메뉴등록3곳에 해당합니다.
- v0.778 대비 본문 **20/10,728항목 변경**, 나머지10,708항목 유지. v0.778의 재채기2자막 `에.. 에취!`, 미카의 `결혼하셨죠, 그렇죠?`, 기존 `접수처` 수정을 모두 유지합니다.
- **보이스 자막·음성·자막 시각·오프닝·렌더러·코어3종은 변경하지 않았습니다.** v0.778 r50 코어와 완전한 코어 소스/라이선스/빌드 기록을 바이트 동일하게 재사용합니다. 빌드 기록 안의 v0.778 표기는 해당 코어의 실제 제작 버전입니다.

전체 문맥 재검수 요청은 별도로 진행 중입니다. 이번 릴리스를 보이스 및 모든 텍스트의 새 전수 검수 완료판이라고 표시하지 않습니다. 다른 지역의 모든 수사·잡담 문장을 소개로 간주해 이름을 일괄 추가한 것도 아닙니다.

## 설치와 업데이트

1. `SnatcherKRInstaller.exe` 또는 `MegaCD-Snatcher-Kr-v0.8-Windows-Patcher.zip`을 받습니다. ZIP에는 같은 EXE와 설명·라이선스가 들어 있습니다.
2. 본인이 보유한 미국판 원본 `Snatcher (USA).bin`을 지정합니다. 아래 원본 해시와 정확히 일치해야 하며, 이미 패치된 게임은 입력으로 사용하지 않습니다.
3. 약700MB 이상 여유가 있는 **기존의 빈 폴더**를 출력 위치로 선택합니다. 패처가 새 게임 BIN/CUE, Windows·Android ARM64·Linux x86_64 코어, 정보 파일, 소스와 고지를 출력합니다. 원본·기존 파일·RetroArch·APK를 덮어쓰지 않습니다.
4. 결과 `Snatcher-KR-v0.8.bin`과 `Snatcher-KR-v0.8.cue`를 함께 보관하고, 해당 플랫폼의 **전용 코어로 CUE를 실행**합니다. BIOS는 사용자가 별도로 준비해야 합니다.

**v0.778 이하 및 로컬 힌트 r1/r2/r3 사용자는 원본에서 v0.8로 다시 패치해야 합니다.** 코어만 바꿔서는 이번 본문 수정이 적용되지 않습니다. v0.778 r50 코어는 그대로 사용해도 됩니다. 그보다 오래된 코어는 동봉 파일로 교체하세요.

저장 파일은 먼저 백업하세요. 기존 세이브스테이트에는 수정 전 대사 메모리가 남아 있을 수 있습니다. 게임을 완전히 종료·재실행하고 **게임 내 저장으로 불러온 다음 장소에 재진입**하세요. 파일명이 바뀌어 저장이 보이지 않으면 원래 저장을 보존한 채 RetroArch의 저장 이름/경로 설정을 확인하세요. 모든 세이브스테이트 호환성을 보증하지 않습니다.

Windows가 없다면 BPS 지원 패처로 원본에 `Snatcher-KR-v0.8.bps`를 적용하고 결과 이름을 `Snatcher-KR-v0.8.bin`으로 맞춥니다. 제공 CUE와 같은 폴더에 두고 플랫폼에 맞는 코어를 별도로 받으세요. Android SO와 Linux SO는 서로 다른 파일입니다. 자세한 플랫폼별 설명과 기존 화면 예시는 [README](../README.md)에 있습니다.

## 실제 확인 범위

- 자동시험 **102/102 통과**: 안전한 메뉴 저장 위치, 기존 접수처 보존, 겹침·범위초과 거부, 힌트/소개 누락 방지, 본문 인코딩, 편집기, 설치 입력 거부·롤백 등.
- 실제 설치된 M68000 메뉴 등록/복사 루틴 분리실행 **48경우**: 새 위로하기18경우와 기존 접수처30경우. 소개·힌트18항목의 본문 읽기 **88구간**도 통과했습니다. 이 검사는 실제 게임 장면 재생과 구분합니다.
- 로컬 힌트r3에서 마지막 메뉴 수정을 통합하면서 전체265,813섹터 중4섹터만 바뀜을 확인했습니다. 나머지 섹터, ISO/CUE 구조, 원래 본문·폰트·음성 주소와 퍼즐 정답 키를 보존했습니다. 변경된 섹터의 EDC/ECC도 유효합니다.
- BPS 두 번 생성 결과 동일, 모든 적용 동작·원본/결과/패치 CRC·목표 바이트 대조 통과.
- **배포할 최종 EXE 자체**의 `--verify`/`--install`이 성공했습니다. 실제 미국판625,192,176바이트 원본을 적용한 결과 **11/11출력의 크기·SHA-256·CRC32 일치**, 원본 불변을 확인했습니다. GUI 조작 관찰 시험이라는 뜻은 아닙니다.
- 코어3종/소스/라이선스/빌드 기록은 v0.778과 동일합니다. Linux 빌드·로드/API1 근거는 [기존 빌드 기록](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr/actions/runs/39104147418)입니다.
